# BVBB Badminton League Dashboard

This project is a web dashboard for the badminton leagues of the [Badminton-Verband Berlin-Brandenburg (BVBB)](https://bvbb-badminton.liga.nu/). It scrapes data from the BVBB's nuLiga installation and displays it in a user-friendly format. Additionally, it allows for some basic data analysis and visualization.

## Disclaimer

This project scrapes publicly available data from [bvbb-badminton.liga.nu](https://bvbb-badminton.liga.nu/) for local analysis and evaluation purposes only. It is not intended to publish or provide an alternative to the official BVBB website.
